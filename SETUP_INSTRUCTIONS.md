# Crop Disease Detector - Setup & Build Instructions

Complete guide to build and deploy the offline crop disease detection Android app.

## Project Structure

```
Cinque/
├── app/                              # React + Capacitor web app
│   ├── src/
│   │   ├── screens/                 # React screens (Main, Preview, Result, Splash)
│   │   ├── styles/                  # CSS files for each screen
│   │   ├── utils/                   # TFLite inference helper
│   │   ├── App.jsx                  # Main app component
│   │   └── main.jsx                 # Entry point
│   ├── android/                     # Android native code (auto-generated by Capacitor)
│   │   └── app/
│   │       ├── src/main/
│   │       │   ├── assets/          # ⚠️ ADD MODEL FILES HERE
│   │       │   ├── java/            # Kotlin code for TFLite
│   │       │   ├── res/             # Android resources
│   │       │   └── AndroidManifest.xml
│   │       └── build.gradle
│   ├── package.json
│   └── capacitor.config.json
├── model.tflite                     # Your TFLite model (copy to assets)
├── labels.txt                       # Disease labels (copy to assets)
└── class_names.json                 # Class mapping (copy to assets)
```

## Prerequisites

1. **Node.js & npm**
   - Download from https://nodejs.org/ (LTS version recommended)
   - Verify: `node --version` and `npm --version`

2. **Java Development Kit (JDK 11+)**
   - Required for Android development
   - Download JDK 11 or 17

3. **Android SDK**
   - Install Android Studio from https://developer.android.com/studio
   - Install Android SDK 34 (or latest)

4. **Git**
   - Download from https://git-scm.com/

## Step 1: Setup Development Environment

### Windows

1. **Install Node.js and npm**
   ```
   Node.js download link: https://nodejs.org/
   Choose LTS version and install
   ```

2. **Verify Installation**
   ```powershell
   node --version
   npm --version
   ```

3. **Install Android SDK via Android Studio**
   - Download Android Studio
   - Open it and go to SDK Manager (Tools → SDK Manager)
   - Install:
     - SDK Platform API Level 34
     - Build-Tools 34.0.0
     - Android Emulator (optional)
     - Platform Tools

4. **Set ANDROID_HOME Environment Variable**
   ```powershell
   # In PowerShell (as Administrator):
   [Environment]::SetEnvironmentVariable("ANDROID_HOME", "C:\Users\YourUsername\AppData\Local\Android\Sdk", "User")
   ```

---

## Step 2: Copy Model Files to Assets

Before building, you MUST add your TensorFlow Lite model files to the Android assets folder.

1. **Create assets directory (if it doesn't exist)**
   ```
   app/android/app/src/main/assets/
   ```

2. **Copy these files to the assets folder:**
   - `Model_V5.tflite` → rename to `model.tflite`
   - `labels.txt`
   - `class_names.json`

   **Final location:**
   ```
   app/android/app/src/main/assets/
   ├── model.tflite
   ├── labels.txt
   └── class_names.json
   ```

⚠️ **CRITICAL:** The app will crash if these files are missing!

## Step 3: Install Dependencies

```powershell
cd app
npm install
```

This will install all React and Capacitor dependencies.

---

## Step 4: Build React App

```powershell
npm run react:build
```

This creates the optimized web build in the `dist/` folder that will run inside the Android app.

---

## Step 5: Set Up Capacitor & Android Project

### First Time Only:

```powershell
# Add Android platform
npm run cap:add:android

# This creates the android/ folder with full native project
```

### Sync Changes (After React Code Changes):

```powershell
npm run cap:sync
```

---

## Step 6: Build APK

### Open Android Studio

```powershell
npm run cap:open
```

This opens the Android project in Android Studio.

### Build APK in Android Studio

1. Go to **Build → Build Bundle(s) / APK(s) → Build APK(s)**
2. Wait for build to complete
3. APK will be at: `app/android/app/build/outputs/apk/debug/app-debug.apk`

### OR Build via Command Line

```powershell
cd app/android
./gradlew assembleDebug

# Release APK (needs keystore):
./gradlew assembleRelease
```

---

## Step 7: Install APK on Device

### Via USB (Recommended)

1. **Enable Developer Mode on Android:**
   - Go to Settings → About Phone
   - Tap "Build Number" 7 times
   - Go to Developer Options → Enable "USB Debugging"

2. **Connect phone via USB**

3. **Install APK:**
   ```powershell
   cd app
   adb install android/app/build/outputs/apk/debug/app-debug.apk
   ```

### Via Android Studio

1. Click **Run → Run 'app'**
2. Select your connected device
3. Click OK

### Via Emulator

```powershell
# List available emulators
adb devices

# Run app on emulator
npm run cap:run
```

## Troubleshooting

### ❌ "Model not found" Error
**Solution:** Check that model files are in `android/app/src/main/assets/`

### ❌ "Camera permission denied"
**Solution:** Go to Settings → Apps → Crop Disease Detector → Permissions → Enable Camera

### ❌ Build fails with "missing build tools"
**Solution:** Open Android Studio → SDK Manager → Install missing SDK components

### ❌ Gradle sync fails
**Solution:**
```powershell
cd app/android
./gradlew clean
./gradlew build
```

### ❌ Model inference is slow
**Solution:** This is normal for first run. TensorFlow Lite compiles optimizations on first execution.

### ❌ App crashes on startup
**Solution:**
1. Check logcat: `adb logcat | grep Crop`
2. Verify model files exist in assets
3. Check that labels.txt has correct format

## File Format Requirements

### labels.txt Format
```
1	Apple___Apple_scab
2	Apple___Black_rot
3	Apple___Cedar_apple_rust
...
```
- Tab-separated: index + disease name
- Must match model output classes exactly

### class_names.json Format
```json
{
  "Apple___Apple_scab": "Apple Scab",
  "Apple___Black_rot": "Black Rot",
  ...
}
```

### model.tflite
- Must be TensorFlow Lite format
- Expected input size: 224×224 pixels
- Float32 input/output

## Creating Release APK

For Google Play Store or distribution:

### 1. Create Signing Key
```powershell
cd app/android/app
keytool -genkey -v -keystore release.keystore -alias crop-detector -keyalg RSA -keysize 2048 -validity 10000
```

### 2. Update Gradle (android/app/build.gradle)
```gradle
signingConfigs {
    release {
        storeFile file('release.keystore')
        storePassword 'your-password'
        keyAlias 'crop-detector'
        keyPassword 'your-password'
    }
}

buildTypes {
    release {
        signingConfig signingConfigs.release
        minifyEnabled true
    }
}
```

### 3. Build Release APK
```powershell
./gradlew assembleRelease
```
